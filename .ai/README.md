# `.ai/` - what an agent reads

**`.ai/platform/` ships with the platform. Everything else here is this project's.**

That one line is the whole rule, and it is what makes the platform updatable: an update
replaces `.ai/platform/` wholesale, because a project never writes there. It writes in the
directories beside it, which have the same names and the same shape.

| This project's | What goes in it | The platform's counterpart - read it, never edit it |
|---|---|---|
| [`adr/`](adr/README.md) | Architectural decisions, numbered from 0001 | [`platform/adr/`](platform/adr/README.md) |
| [`specs/`](specs/README.md) | One spec per non-trivial feature - `make module` writes its stub here | [`platform/specs/`](platform/specs/README.md) |
| [`lessons/`](lessons/README.md) | Mistakes understood while building this project | [`platform/lessons/`](platform/lessons/README.md) |
| [`analysis/`](analysis/README.md) | Audits and investigations of this project | [`platform/analysis/`](platform/analysis/README.md) |
| `docs/`, `skills/` | Guides and procedures of your own, if you write any | [`platform/docs/`](platform/docs/README.md), [`platform/skills/`](platform/skills/README.md) |
| - | The platform's design, phase by phase | [`platform/PLAN.md`](platform/PLAN.md) |
| `inventory.json` | Generated by `make inventory` from this project's code | - |

Which side a new record belongs to is not a judgement call. `.project.json` says
`"initialized": false` in the platform's own repository - where this project side must stay
empty apart from its indexes, because whatever is in it would be handed to every new project
as its own - and `true` in a project made from it. `make docs-check` enforces both halves.

A project that disagrees with a platform decision does not edit the platform's record: it
writes its own ADR that names the one it departs from. Decision:
[ADR-0023](platform/adr/0023-platform-and-project-knowledge-are-separate-trees.md).
